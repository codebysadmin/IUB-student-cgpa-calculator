# IUB-student-cgpa-calculator
As an IUB Student I made a cgpa Calculator based on IUB grading systems 


A object-oriented Python application designed to calculate IUB course grade points and overall CGPA based on credit hours and marks.

## Features
- Object-Oriented Programming (OOP) design pattern with `Student` and `Course` classes.
- Dynamic input for course credits, code, and numerical marks.
-Independent university, Bangladesh (IUB) grading point calculation logic.
- Clean summary report output in the terminal.

## How to Run
```bash
python gpa_calculator.py
